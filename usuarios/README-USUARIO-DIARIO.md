# Usuário diário

Conta Windows de uso cotidiano. O papel recomendado é **Standard** depois que a conta administrativa de recuperação tiver sido testada.

## Diretrizes

- não trabalhar permanentemente como administrador;
- manter projetos compartilhados com agentes no diretório `Development` configurado;
- manter dados pessoais no diretório `PersonalData` configurado;
- preferir instalação por usuário quando o programa não precisa ser global;
- não mover o perfil do Windows ou `AppData` para o disco de dados;
- documentar ou automatizar configurações necessárias para reconstruir a máquina;
- evitar programas sem finalidade definida.

## Antes de instalar um programa

1. Existe uma necessidade atual?
2. Uma ferramenta instalada já atende à necessidade?
3. O programa precisa de privilégios administrativos?
4. Precisa executar como serviço?
5. Pode ser instalado por usuário ou usado como aplicativo portátil?
6. A recuperação continua possível se o disco de dados for desconectado?
