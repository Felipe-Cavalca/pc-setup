# Administrador de recuperação

Conta humana com papel **Administrator**, reservada para manutenção e recuperação.

Não é uma conta de uso diário. Ela atende tarefas como drivers, recursos do Windows, recuperação de ACL, Hyper-V, WSL e reparos do host.

Navegador pessoal, e-mail, jogos, IDE e projetos não devem permanecer nesse perfil.

A senha deve ser forte, exclusiva e nunca armazenada em script ou repositório. O login precisa ser testado antes de o usuário diário perder privilégios administrativos.
