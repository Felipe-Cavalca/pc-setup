# Arquivos da mídia

Copie `Validar-Midia.cmd` e `Validar-Midia.ps1` para a raiz do pendrive e execute o `.cmd` antes da instalação.

O arquivo `autounattend.pt-BR.opcional.xml` é opcional. Para usá-lo, copie-o para a raiz e renomeie a cópia para `autounattend.xml`. Ele apenas define idioma, região e teclado em português do Brasil.

Não copie instaladores para este diretório e não acrescente comandos ao XML. Toda configuração pós-instalação pertence ao `pc-setup`.
